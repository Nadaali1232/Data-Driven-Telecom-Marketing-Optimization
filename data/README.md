# Data

## Raw dataset

Download the IBM Telco Customer Churn file from Kaggle and place it here:

```
data/WA_Fn-UseC_-Telco-Customer-Churn.csv
```

<https://www.kaggle.com/datasets/blastchar/telco-customer-churn> (7,043 customers, 21 columns).
Check the dataset's license on Kaggle before redistributing the file.

## Using the notebooks

- **Google Colab:** upload the CSV to the session; the notebooks read `/content/WA_Fn-UseC_-Telco-Customer-Churn.csv` (notebook 01) or the working directory (notebook 02).
- **Locally:** change the path in the first data-loading cell to `../data/WA_Fn-UseC_-Telco-Customer-Churn.csv` (notebook 01) and run notebook 02 from the folder that contains the CSV.
